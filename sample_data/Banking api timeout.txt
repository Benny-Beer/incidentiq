INCIDENT REPORT
Date: 2024-11-08
Reported by: Priya Nair, Senior Platform Engineer
Severity: P1 — Regulatory notification required
Duration: 58 minutes (11:03 UTC - 12:01 UTC)

INCIDENT SUMMARY
Banking transfer API became unavailable for 58 minutes. Customers unable to
initiate domestic or international transfers. 1,847 transfer requests failed.
No financial data lost — all failed transactions rolled back cleanly.
Regulatory body notified per compliance requirements (>30 min outage threshold).
Incident caused by TLS certificate configuration change that broke mutual
authentication with the core banking system.

SYSTEM BACKGROUND
- Transfer API handles ~200 requests/minute during business hours
- Communicates with CoreBanking system via mutual TLS (mTLS)
- mTLS requires both client and server to present valid certificates
- Certificate rotation scheduled quarterly — last rotation: 3 months ago
- Config change deployed at 10:55 UTC: updated cipher suite list per new
  security policy (removed 3DES, added ChaCha20-Poly1305)

ADDITIONAL OBSERVATIONS
- Cipher suite change was required by new internal security policy (compliance deadline: end of month)
- Security policy change was reviewed and approved by CISO office
- CoreBanking system version compatibility was not checked before cipher suite update
- CoreBanking v4.1 is scheduled for upgrade to v5.0 in Q1 2025 — v5.0 supports ChaCha20-Poly1305
- Canary health check at 10:58 UTC passed because /health endpoint does not make CoreBanking calls
- Circuit breaker opened at 11:04 UTC, preventing retry storms — worked as designed
- All 1,847 failed transactions rolled back cleanly — no partial transfers or data corruption
- International transfer queue was separately paused by operations team at 11:10 UTC as precaution
- A separate unrelated DNS warning appeared in logs at 11:19 UTC for an internal monitoring service
- Customer support received 203 inbound contacts during the incident window
- Identical cipher suite issue was flagged in a dependency review 6 months ago but not actioned
